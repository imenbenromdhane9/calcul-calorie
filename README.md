# calcul-calorie
Description :
Projet de site web permettant de calculer les besoins caloriques quotidiens d’un utilisateur selon son âge, sexe, poids, taille et niveau d’activité. Développé en HTML, CSS et JavaScript .

Fonctionnalités :

-Saisie interactive des données personnelles (âge, sexe, poids, taille, niveau d’activité)

-Calcul automatique des besoins caloriques quotidiens

-Affichage du résultat instantané sur la page

-Interface simple et responsive

Technologies : HTML, CSS, JavaScript
